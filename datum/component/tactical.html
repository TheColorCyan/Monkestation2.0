tactical
/datum/component/tactical

A simple component that replaces the user's appearance with that of the parent item when equipped.

Vars

allowed_slotThe allowed slot(s) for the effect.
current_slotThe slot the item is currently equipped in.
waddlesWhether the holder should waddle while using the tactical disguise.

Procs

on_name_inquiryReplaces the holder's visible identity with the tactical item's name.
